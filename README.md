# 云仓商城 · 电商商品管理系统（高保真交互原型）

> 一份可直接演示的商品管理后台高保真原型，用于产品经理面试作品展示。
> 纯原生 HTML/CSS/JS 实现，**单文件、零依赖、双击即开**，离线可用。

## 如何打开

直接双击 `index.html`，用任意浏览器（Chrome / Edge / Safari）打开即可。

> 建议演示时全屏浏览器（F11），并在浏览器缩放设置为 100% 以获得最佳效果。

## 作品定位

- **业务场景**：电商平台（B2C）商品运营后台
- **目标用户**：商家 / 运营 / 仓管
- **核心价值**：商品全生命周期管理 —— 从「创建 → 上架 → 库存 → 分类」一条龙

## 模块清单

| 模块 | 核心功能 | 交互亮点 |
|------|----------|----------|
| 📊 数据总览 | 在售商品、总库存、库存预警、待上架等 KPI；分类商品数柱状图；库存流水 | 一眼看清经营健康度 |
| 📦 商品列表 | 搜索、分类/状态筛选、批量上架/下架/删除、分页（每页条数可调） | 多条件**实时过滤**、状态标签 |
| ➕ 商品新增/编辑 | 基本信息、主图、价格库存、多规格、描述 | **多规格自动生成 SKU 组合**（笛卡尔积） |
| 🏬 库存列表 | 库存水位、预警、入库/出库、分页 | **入库/出库真实扣减库存**，触发预警 |
| 🧾 库存流水 | 入库/出库记录、类型筛选、搜索、分页 | 每一笔库存变动可追溯；**只读台账**，写操作统一收在库存列表 |
| 🗂️ 分类管理 | 多级分类树、增删改、分类下商品数 | 树形结构联动商品数 |

## 面试演示路径（建议顺序，约 5 分钟）

1. **数据总览**：介绍 KPI 卡与库存预警 —— 说明「我关注的是经营结果而非功能堆砌」
2. **商品列表 → 筛选**：搜索「手机」、按分类/状态筛选，演示多条件过滤 —— 讲「搜索效率」
3. **新增商品 → 多规格**：添加「颜色/尺码」两个规格，展示 **SKU 自动生成** —— 这是全作品最亮的交互点，重点讲
4. **上架流程**：把草稿商品上架、批量下架 —— 讲「状态机设计」
5. **库存列表 → 出库**：对低库存商品出库，演示库存扣减与预警，再切到**库存流水**页查看记录（只读台账，写操作统一在库存列表） —— 讲「库存预警的业务闭环 + 流水可追溯」
6. **分类管理**：新增/删除分类，讲「类目树的扩展性」

## 面试讲解要点（产品思考）

准备面试时，可以主动抛出以下产品视角（体现 PM 而非 UI 的深度）：

- **状态机设计**：商品状态「草稿 / 出售中 / 已下架 / 售罄」，售罄由「上架 + 库存为 0」自动推导，而非人工维护，避免状态不一致
- **SKU 与规格的建模**：规格 × 规格值做笛卡尔积生成 SKU，支持「颜色 × 尺码」等任意维度组合，库存/价格下沉到 SKU 级
- **库存预警闭环**：预警值触发「预警 / 售罄」状态，反哺总览 KPI，形成「监控 → 提醒 → 补货」闭环
- **类目树的可扩展性**：支持多级分类、分类下商品数实时统计、有商品时禁止删除（数据一致性保护）
- **列表页的信息架构**：筛选收敛在顶部（缩小结果集）、分页收敛在底部（浏览结果集），每页条数可调；**库存流水刻意做成只读台账**，把「写操作」全部收在库存列表 —— 同一操作只有一个入口，避免用户误以为在流水页改数据会回写库存

## 技术说明

- 单文件自包含，无构建、无 CDN、无外部依赖，离线可用
- SPA 视图切换模拟后台多页路由；内存 mock 数据支撑真实增删改查
- 商品图用 emoji + 渐变色占位，保证离线演示效果
- 图表为纯 CSS 实现，不依赖图表库
